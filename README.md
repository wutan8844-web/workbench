# 进度本 · 个人成长工作台

面向手机长期使用的个人系统：每天20分钟从零学前端与后端，同时管理基金、收支、任务、复盘、备忘、英语和真实AI新闻。

## 已实现

- 20节第一阶段互动代码课程：讲解、可编辑代码、实时运行、提示、自动检查、真实进度。
- 基金持仓：基金代码校验、最新正式净值、收益计算、来源和更新时间；不编造已经失效的盘中估算。
- 收支账本：收入、支出、转账、分类统计、七天趋势、编辑与删除。
- 每日任务：优先级、待办/进行中/完成、日期和说明。
- 每日复盘：完成、收获、不足、明日改进、状态和历史回看。
- 独立备忘录：标签、搜索、编辑、删除。
- 四年级起点英语：每日5词、发音、例句和间隔复习。
- 真实AI新闻：公开技术社区回退源，以及Supabase官方源聚合函数。
- PWA：可安装到手机桌面，静态内容可离线打开。
- Supabase：邮箱验证码、跨设备同步和逐行访问权限。

## 本地运行

```bash
pnpm install
pnpm dev
```

没有 `.env.local` 时会进入本机模式，功能数据保存在当前浏览器；连接方法见 [SUPABASE_SETUP.md](./SUPABASE_SETUP.md)。

## 部署

仓库已包含 GitHub Pages 工作流。连接 Supabase 后，在 GitHub 仓库中配置两个 Actions Variables，再把 Pages Source 设为 GitHub Actions。

旧版单文件已保存在 `legacy/index.v1.html`，没有覆盖。
